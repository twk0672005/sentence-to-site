# Visual direction

## Start with a visible premise

Before choosing an effect, state the audience, the one-sentence promise, the desired first impression, and the dominant contrast. A page can be quiet, editorial, technical, playful, or cinematic; it cannot be all of them at once.

## Turn premise into decisions

| Layer | Decide |
| --- | --- |
| hierarchy | What must be understood in the first viewport? |
| type | What scale, density, and rhythm make that hierarchy felt? |
| material | What texture, color, image treatment, or empty space supports the premise? |
| interaction | Where does feedback reduce uncertainty or reward exploration? |
| motion | Which beat becomes clearer through movement rather than decoration? |

## Critique the weakest visible point

After a working browser view exists, look for the one flaw that most makes it feel generic: unclear hierarchy, weak contrast, repetitive cards, empty visual material, unearned effects, unreadable copy, or a desktop-only composition. Repair that before adding another feature.
