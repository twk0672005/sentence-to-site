# Delivery Handoff

A useful handoff lets another person run the result, inspect the same evidence, understand the bounded claim, and continue from a known baseline.

Include the goal, baseline, changed areas, run/verify path, evidence location, verdict, known limits, and one recommended next action. State unresolved issues plainly instead of burying them in a completion message.

Exclude credentials, environment files, private assets, caches, dependency trees, unrelated history, and client-identifying evidence. Use a clean export when a working tree or Git history is not safe to publish.

Read `../../references/delivery-handoff.md` and use `../../templates/handoff.md`. Load `browser-evidence` first when the evidence verdict has not been determined.
