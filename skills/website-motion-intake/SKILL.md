# Website Motion Intake

Understand the host project before changing it. The existing stack and strongest accepted baseline outrank a preferred architecture.

Capture only information needed for the task: runtime, run/build commands, entry route, content/style/motion owners, verification path, protected files, and rollback point. Say the result back in one sentence before implementation.

Do not replace frameworks, add paid services, alter deployment, expose previews, or touch credentials as a side effect of visual work. Create folders only when they make the next change easier to find.

Use `../../references/project-intake.md` for decision guidance and `../../templates/project-intake.md` for a copyable working form.
