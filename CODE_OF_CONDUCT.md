# Code of Conduct

We want this project to be a welcoming place for people building thoughtful browser experiences.

Be respectful, assume good intent, critique work rather than people, and make room for different levels of experience. Harassment, discrimination, threats, doxxing, and sharing another person's private material are not acceptable.

If a concern cannot be resolved in discussion, report it privately through the repository host or the maintainer's private contact channel. Maintainers may remove content or restrict participation to protect contributors and the project.
