## Change

- keep the daily path at README + one domain workflow;
- separate Micro, Choreographed and Cinematic motion so small UI work is not inflated into WebGL;
- keep `threejs-cinematic-motion` as scene/directing/quality authority and use the ten commit-pinned `threejs-*` topics only as narrow technical references;
- preserve official Three.js r185 documentation and executable browser evidence above third-party examples;
- add conditional Scene input, Scene lock and Technical lock records for real Three.js/WebGL work;
- split Refero concept research into Product UI screens/flows and Refero Styles visual-system lanes;
- make supplied references and strongest accepted baselines authoritative; Refero only fills named gaps;
- forbid Refero public-web scraping/crawling/bulk download and keep official MCP/API, sign-in, upload and payment approval-bound;
- add one research-backed high-end public review with hard blockers, one highest-impact repair and a fixed stop point;
- keep `public-ready production candidate` separate from deployment or publishing authorization;
- replace bundled active skill copies with an index-only optional library to prevent stale duplication and unrelated runbooks entering the package.
