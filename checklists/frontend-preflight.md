# Frontend Preflight Checklist

- [ ] 已讀 brief / reference / audience
- [ ] 已寫 Design Read
- [ ] Hero 第一屏有主視覺，不是純文字 + gradient
- [ ] CTA 可見、清楚、對比足夠
- [ ] 沒有 generic 3 cards / fake dashboard / fake screenshot
- [ ] 文字不過量，hero subtext 夠短
- [ ] Mobile first fold 可讀
- [ ] 無 internal QA / mock / demo 字眼出現在 public UI
- [ ] 無 console / page errors
- [ ] 有 desktop / mobile screenshots
- [ ] 有一句人話質量判斷
