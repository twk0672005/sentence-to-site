# Frontend Preflight Checklist

- [ ] 已讀 brief / reference / audience
- [ ] 已鎖 work depth、delivery intent、required evidence、stop condition
- [ ] Existing site 已做 Product truth trace 同 Preservation map（如適用）
- [ ] 第一屏有清楚產品 thesis、proof 同 action；signature 可來自真內容、
      instrument、type、image或interaction，唔強制裝飾主視覺
- [ ] CTA 可見、清楚、對比足夠
- [ ] 沒有 generic 3 cards / fake dashboard / fake screenshot
- [ ] 文字不過量，hero subtext 夠短
- [ ] Mobile first fold 可讀
- [ ] 無 internal QA / mock / demo 字眼出現在 public UI
- [ ] 無 console / page errors
- [ ] Evidence coverage 按 tiny / normal / serious / redesign 明示狀態
- [ ] Normal以上有 desktop / mobile；Serious/Redesign再驗320/zoom
- [ ] 有一句人話質量判斷
